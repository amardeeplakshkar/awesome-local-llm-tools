# Contributing

Thanks for helping improve Awesome Local LLM Tools. This list stays simple: real local LLM tools, grouped by job, one line each.

## How to add an entry

1. Pick the right section table in README.md: Run Models Locally, Serve and Chat, or Local Coding and Helpers.
2. Add one line in this format: `| [Name](URL) | What it does |`
3. Link to the tool official GitHub repo or official site.
4. Keep the description to one short line that says what the tool does.

## Rules

- The tool must be a real tool for running LLMs locally.
- The link must load and match the tool name and description.
- One entry per tool.
- No duplicates.
- Use a hyphen - not an em dash, in the name and description.
- No rate limits, speed tiers, comparison tables or code snippets.

Maintainers may edit entries for clarity, move them to a better section, or remove entries that no longer fit.
